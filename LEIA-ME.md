# 📁 Pasta de Mudanças — `_mudancas/`

Esta pasta contém **apenas os arquivos que foram modificados** pela IA.  
A estrutura de subpastas aqui espelha exatamente a estrutura do projeto principal.

---

## ✅ Como usar

1. Quando a IA fizer ajustes no projeto, ela copiará cada arquivo modificado para cá, **mantendo o mesmo caminho relativo**.
2. Você envia **apenas esta pasta** ao servidor (ou copia só os arquivos listados abaixo).
3. No servidor, cole os arquivos nos mesmos caminhos correspondentes.

---

## 🗂️ Exemplo de estrutura

Se a IA modificou:
- `blueprints/estoque/routes.py`
- `templates/estoque/listar.html`
- `static/js/app.js`

Você verá aqui:
```
_mudancas/
  blueprints/
    estoque/
      routes.py       ← copie para blueprints/estoque/routes.py no servidor
  templates/
    estoque/
      listar.html     ← copie para templates/estoque/listar.html no servidor
  static/
    js/
      app.js          ← copie para static/js/app.js no servidor
```

---

## 🔄 Fluxo de limpeza

Após subir os arquivos ao servidor, **limpe esta pasta** para a próxima rodada de mudanças.  
Você pode rodar no PowerShell:
```powershell
Get-ChildItem "c:\Users\User\Desktop\sollus_connected\_mudancas" -Exclude "LEIA-ME.md" | Remove-Item -Recurse -Force
```
